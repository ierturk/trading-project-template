Side file of close-loop.md. Read it ONLY when step 3c/3d says so (an open spread exists, or an entry day for the Open Check). Both books are optional, paper only, report only.

3c. [SPREAD] only when SWE SPREAD STATUS is ENABLED. Rules: `strategies/spreads.md`. SPY, QQQ and GLD only; one spread per underlying at a time; spreads do not use stock slots. ENTRIES ONLY ON A SPREAD ENTRY DAY: the "SPREAD ENTRY DAY" line of `trend_hold_check.py` (first trading day of a month, with the month-end status and month-end close of SPY, QQQ, GLD). On any other day there are NO spread suggestions. On an entry day, for each of SPY, QQQ, GLD that is IN and has no open "SWE-SPREAD" row in `sim_journal`: `get_option_parameters` (contract id from `state/swe_contracts.json`), take the monthly expiry at least 45 days out (the Thursday if that Friday is a holiday); `get_option_data` for that expiry; long call = strike nearest the month-end close, short call = strike nearest close x 1.05. Print: "SPREAD <SYM> exp <date> buy <K1> sell <K2>: debit $<ask of long minus bid of short> per share = $<x> per spread (max loss), leg bid/ask widths $<sum>". OUT prints "SPREAD <SYM>: no entry (OUT at the month end)"; an open spread prints "no entry (spread still open)". SKIP with the reason if the debit is above $20.00 per share ($2,000), the two legs' bid/ask widths sum above the larger of $0.50 and 8% of the debit per share, or option data is missing: never guess a price. Every day, for every open "SWE-SPREAD" row: mark = long bid minus short ask, P&L = (mark - entry debit) x 100 x qty, days to expiry; print "CLOSE <SYM> (7 days to expiry)" at 7 calendar days or fewer. That is the only exit. BUDGET LINE: -$2,000 from the book's peak (closed P&L plus marks, from the first fill): a budget for the paper test, not an alarm; at or past it print a line starting "SPREAD REVIEW" as the closing line ("budget reached: no new spreads, open spreads run to their exit, review together"). At most 3 chains + 3 quotes for entries and 1 per open spread, in batches within the IBKR limits. You enter and exit by hand (one combo limit order near the mid). Never create order instructions. If step 3 did not run or option tools fail: "SPREAD not run (<reason>)".

3d. [PUTCS] only when SWE PUTCS STATUS is ENABLED. Rules: `strategies/spreads.md`. Open spreads come from `sim_journal` rows with strategy "SWE-PUTCS" (the second paper account is not read); quotes from the IBKR option tools (market data only). Entries only on a spread entry day, as in 3c. For each of SPY, QQQ, GLD that is IN and has no open "SWE-PUTCS" row: monthly expiry at least 45 days out; short put = strike nearest the month-end close, long put = strike nearest close x 0.97. Print "PUTCS <SYM> exp <date> sell <K1>P buy <K2>P: credit $<short bid minus long ask> per share = $<x> per spread, width $<K1-K2>, max loss $<(width-credit) x 100>, leg bid/ask widths $<sum>". SKIP if credit < 15% of the width, max loss above $3,500, leg bid/ask widths above the larger of $0.50 and 8% of the credit per share, or data missing. Every day, for every open "SWE-PUTCS" row: mark (cost to close) = short ask minus long bid, P&L = (entry credit - mark) x 100 x qty, days to expiry; print "CLOSE <SYM> (7 days to expiry)"; print "PUTCS ALERT <SYM>" if the mark loss is $1,500 or more (review together; nothing closes by itself). REVIEW LINE: -$1,500 from the book's peak; at or past it print "PUTCS REVIEW" as the closing line (no new PUTCS spreads, open spreads still run to their 7-day exit, entries restart only on your word). Note: one losing SPY or QQQ spread can reach this line; that is accepted and is not a rule break. Stay under 30 calls a minute across 3c and 3d. Never create order instructions. If step 3 did not run or option tools fail: "PUTCS not run (<reason>)".
